Credenciales de Tuya Cloud API

Ingresa tus datos del Portal Desarrollador de Tuya IoT. Las credenciales se guardan localmente en tu navegador (`localStorage`).

Ejemplos: https://corsproxy.io/? o tu propio servidor proxy de Node.js / Cloudflare Worker.

Guía: Obtener Credenciales de Tuya Cloud

Sigue estos pasos para vincular tu cuenta Smart Life / Tuya y obtener tu Client ID, Client Secret y Device ID de manera totalmente gratuita.

1

Crear cuenta en Tuya Developer Platform

Ingresa en iot.tuya.com y regístrate con tu correo electrónico.

2

Crear un Proyecto Cloud

En el menú lateral, ve a Cloud → Development → Haz clic en Create Cloud Project. Selecciona tu industria (ej. Smart Home), tu región de centro de datos (EE.UU., Europa, etc.) y guarda.

3

Copiar Client ID & Client Secret

Dentro de tu proyecto recién creado en la pestaña Overview, verás tus credenciales: Access ID/Client ID y Access Secret/Client Secret. Copia ambos en la pestaña Ajustes de esta web app.

4

Vincular tu App Tuya / Smart Life

En el proyecto Cloud de Tuya, ve a la pestaña Devices → Link Tuya App Account. Escanea el código QR desde tu app "Tuya Smart" o "Smart Life" en tu iPhone (en la app ve a Yo → icono de código QR arriba).

5

Obtener el Device ID de tu interruptor

Una vez vinculada tu cuenta, aparecerán todos tus dispositivos listados en la web. Copia el **Device ID** del interruptor que deseas controlar.
